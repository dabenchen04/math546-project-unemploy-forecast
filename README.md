## Reproduce

With Python 3.12:

```bash
python -m pip install -r requirements-starter.txt
```

Then run all cells of `capstone_stage1_chen_ben.ipynb` in order from this folder (about 12 minutes). To rebuild the HTML:

```bash
quarto render capstone_stage1_chen_ben.ipynb --to html
```
